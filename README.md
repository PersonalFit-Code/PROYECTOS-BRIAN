# Proyectos Brian

Repositorio con los proyectos web de Brian. Cada proyecto vive en su propia carpeta.

## Proyectos

- **tixola-taperia** — página web de la tapería Tixola.
- **dos-puertas** — web del Café Bar Dos Puertas (Ourense). Primera versión del frontend; pendientes en `dos-puertas/README.md`.
- **vapi-voice-agent** — servidor Express + TypeScript que atiende los webhooks del agente de voz de Vapi.
- **andrea-salon** — web + reservas + WhatsApp + bonos + panel de administración para el salón de Andrea (Ourense). En fase de plan: `andrea-salon/PLAN.md`.
- **estudio-adrian** — app de estudio tipo test (estilo autoescuela) para el curso de incendios de Adrián: extintores, BIEs y detección; examen en modo estudio o examen, orden salteado o por temario, test de errores y asistente IA para dudas. Las preguntas van en `estudio-adrian/src/data/temario.ts`.
